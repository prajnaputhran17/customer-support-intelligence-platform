# Customer Support Intelligence Platform

An end-to-end data engineering and analytics platform for a fictional SaaS customer support company.

## Project Goal

Build a production-style data pipeline that ingests support data through APIs, validates and transforms it, stores analytical data, and provides business insights through Power BI.

## Planned Architecture

API → Python → MySQL → Databricks/PySpark → Bronze → Silver → Gold → SQL → Power BI → Automation

## Technologies

- Python
- FastAPI
- MySQL
- Databricks
- PySpark
- SQL
- Power BI
- Git/GitHub
